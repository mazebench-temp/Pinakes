summary: Antinous tells how Penelope “set up a great loom in the halls” and wove a shroud for Laertes, weaving “the great web” by day and unraveling it by night, until the suitors “caught her unraveling the splendid web” (2.94–109).
# ἱστός is "loom" where it is set up (2.94) and "web" where it is woven and unraveled (2.104, 2.109); the mast of
# 2.424 is excepted in the entry.
en: [web]

“she set up a great loom in the halls and began to weave, / fine and very wide” (2.94–95; see [[the-web-of-penelope]] and [[weaving]]). The upright loom is set up, στησαμένη, as the crew set up the mast at the end of the book (στῆσαν, 2.425; see [[mast]]): ἱστός, “the upright”, is the word for both, and the translation renders it “loom” where it is set up, “web” where it is woven and unraveled (2.104, 2.109), and “mast” on the ship (2.424; see the translation's table of key words). μέγαν ἱστόν is the phrase of Helen's web at Troy (*Iliad* 3.125; see [[helens-web]]). Penelope's is λεπτὸν καὶ περίμετρον, “fine and very wide” (2.95), and ἀγλαός, “splendid” (2.109; see [[splendid]]), and what she weaves on it is a mantle for a shroud (2.97–99; see [[shroud]] and [[cloak]]).
